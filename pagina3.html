GitHub y colaboración

GitHub aloja repositorios de Git en la nube. Allí se guarda el código, se revisa el historial y se invita a otras personas a participar como colaboradores.

Un colaborador puede clonar el repositorio, modificar archivos y subir sus cambios con push, siempre que el dueño le haya dado permiso.

También se pueden crear ramas para probar ideas sin afectar la rama principal, y unirlas después cuando el trabajo esté listo.
