Flujo básico de trabajo

El ciclo diario con Git consta de pocos pasos: revisar el estado, preparar los cambios, confirmarlos y subirlos al servidor.

Primero se modifican los archivos en la carpeta del proyecto; después se eligen cuáles cambios formarán parte del siguiente commit usando el área de preparación (staging area).

Por último, el commit se envía al repositorio remoto con push para que el resto del equipo pueda descargarlo.

Muestra el estado del repositorio y los archivos rastreados y no rastreados.

Agrega todos los cambios y archivos nuevos al área de preparación.

Crea un commit con los cambios preparados y una descripción.

Sube los commits locales al repositorio remoto en GitHub.
